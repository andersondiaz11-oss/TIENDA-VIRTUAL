# TIENDA-VIRTUAL — Messier Divine

Proyecto educativo de un agente de ventas en Python para Messier Divine.

## Objetivo
Aprender Python paso a paso mientras construimos un programa para consultar productos, calcular importes y registrar pedidos de forma local. Más adelante podremos evaluar integraciones con Shopify y canales de atención.

## Ejecutar
1. Instala Python 3.10 o posterior.
2. Abre una terminal en la carpeta del proyecto.
3. Ejecuta: `python main.py` (en algunos equipos: `py main.py`).

## Archivos
- `main.py`: menú principal.
- `productos.py`: catálogo de ejemplo.
- `ventas.py`: validación de cantidades y cálculo de importes.
- `requirements.txt`: dependencias externas (por ahora ninguna).

## Importante
Los productos y precios son **ejemplos**, no corresponden al catálogo real de la tienda. El programa no procesa pagos ni envía pedidos reales. No guardar claves, tokens ni datos personales en el repositorio.
